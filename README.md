Forecasts, hour by hour, how many people watch Grand Theft Auto VI live on Twitch over the 24 UTC hours of its release day, from everything recorded up to the end of its first hour — five quantiles an hour (5%, 25%, 50%, 75%, 95%), scored by pinball loss on the log scale. Method: hour-1-anchored log-ratio quantiles from comparable launches, computed at runtime from the case file.

## Run it

```sh
python3 main.py
```
